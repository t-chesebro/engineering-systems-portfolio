# Engineering Systems Portfolio

Architecture case studies from building autonomous developer systems.

The detailed portfolio lives in the
[project Wiki](https://github.com/t-chesebro/engineering-systems-portfolio/wiki). It focuses on
three related systems:

| System | Engineering focus |
|---|---|
| PowerPoint Autopilot | Autonomous engineering with live runtime validation |
| Teams Bridge | Reliable conversational access to a long-running agent session |
| Firstmate Beta | Event-driven orchestration of distributed autonomous workers |

These pages describe architectural patterns, design decisions, and engineering lessons. They
intentionally omit proprietary source code, internal infrastructure details, credentials, and
confidential operational information.
